# Triage labels

| Vai trò | Nhãn GitHub | Ý nghĩa |
|---|---|---|
| needs-triage | needs-triage | Cần đánh giá và phân loại |
| needs-info | needs-info | Chờ bổ sung thông tin |
| ready-for-agent | ready-for-agent | Đủ đặc tả để agent thực hiện |
| ready-for-human | ready-for-human | Cần người thực hiện |
| wontfix | wontfix | Không triển khai |

Khi skill nhắc đến vai trò triage, dùng đúng nhãn tương ứng trong bảng.
